# Purple Room Incident

**Category:** Forensics  
**Difficulty:** Medium  
**Goal:** Recover the hidden flag.

A workstation in the "Purple Room" produced several artifacts before it was shut down.

You have:
- `incident.log`
- `evidence.png`
- `hashes.txt`

Some evidence is useful. Some is noise.

## Notes

- The image may contain more than what is visible.
- Metadata and appended data can matter.
- Do not assume every Base64-looking string is the flag.
- The final flag format is:

`CTF{...}`

This challenge is designed to benefit from:
- Smart Pre-Scan
- Smart Router
- Tool Planner
- Hypothesis Board
- Stuck Recovery
- Parallel Plan
